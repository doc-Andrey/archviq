# ARCHVIQ Web 3.0

- Новый заголовок: «Как работает именно ваш мозг?».
- Исправлена видимость логотипа ARCHVIQ.
- Строгое переключение RU/EN для основного сайта и когнитивной батареи.
- Удалён декоративный фон с повторяющимися золотыми формулами.
- Основной CTA отделён от золотого брендового акцента и получил контрастный бирюзовый цвет.
- Карточки продуктов больше не имеют фиксированной высоты; добавлен конкретный состав каждого продукта.
- Бесплатный путь объединяет модель 43, опросник архитектуры, когнитивный тест и GAP.
- Платная структура: совместимость $19, выгорание $19, работа с ИИ $19, полный отчёт $39.
- Из клиентского интерфейса удалён термин «поздняя консолидация»; используется понятное «временной акцент развития».
- Расширена биография автора на основе прежнего сайта.
- Встроен импорт CSV когнитивной батареи без недоказанного перевода сырых метрик в оси.
- Добавлен исследовательский RDM-тест v3 с проверкой даты и восстановлением данных после сбоя; исправлена очистка контрольной копии.
- Анализаторы совместимости, выгорания и работы с ИИ включены в пакет с закрытым validation gate.
