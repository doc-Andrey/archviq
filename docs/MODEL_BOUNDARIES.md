# Model boundaries

Baseline A models functional calibration hypotheses, not deterministic anatomical malformation.

The intended target variables concern processing/control properties such as gain, temporal integration, filtering, persistence, switch/update thresholds, hysteresis, recovery, compression and related RS4/v4 parameters.

Content of beliefs, values, goals, learned models and moral behavior are not directly determined by the developmental architecture layer.

For preterm birth, late prenatal windows must stop at actual birth. Extrauterine maturation to term-equivalent age requires a dedicated model and must not be silently treated as ordinary fetal exposure.
