Тест восприятия движения

Вы увидите облако движущихся точек. Часть точек движется в едином направлении — влево или вправо, остальные хаотично. Ваша задача — как можно быстрее и точнее определить общее направление.

Это часть исследовательского проекта об архитектуре обработки информации. Результаты хранятся под вашим кодом участника, а не под именем (псевдонимизированы). Дата рождения — персональные данные; она хранится отдельно от основной базы и используется только для сопоставления с независимой исследовательской моделью, не для идентификации вас в отчётах.

Понадобится точная дата рождения и 8–10 минут без отвлечений. Для ответа удобнее клавиатура (стрелки ← →), на телефоне — кнопки на экране.

ШАГ 2 ИЗ 3

Как отвечать

На экране появится круглое облако точек. Смотрите на него и определите, куда в целом смещаются точки:

← если движение влево   |   → если движение вправо

Сначала — 10 тренировочных попыток с подсказкой, они не учитываются в результатах. Затем — 200 основных попыток с короткими паузами. Такой объём нужен для устойчивой оценки параметров принятия решения. Отвечайте, как только почувствуете уверенность — не нужно ждать до конца показа.

Иногда движение будет почти не различимо — это нормально, отвечайте на основе первого впечатления.
