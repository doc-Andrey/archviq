# Полная замена сайта ARCHVIQ

Этот пакет предназначен для полной замены содержимого репозитория сайта, а не для загрузки одного `app.py`.

1. Сделайте резервную копию текущего репозитория.
2. Удалите старые файлы сайта в репозитории, сохранив только собственные секреты и настройки домена, если они хранятся отдельно.
3. Распакуйте ZIP и загрузите **всё содержимое папки `ARCHVIQ_SITE_FULL_V3`**, включая скрытую папку `.streamlit`.
4. Главный файл приложения: `app.py`.
5. После развёртывания проверьте RU/EN, бесплатный профиль, опросник, когнитивный тест и все платёжные кнопки.

## Где менять ссылки оплаты

Все четыре ссылки находятся в одном словаре `PRODUCTS` в начале `app.py`:

- `compatibility` — совместимость, $19;
- `burnout` — выгорание, $19;
- `ai` — работа с ИИ, $19;
- `full` — полный отчёт, $39.

Смена URL не требует изменений в расчётном ядре или модулях анализа.

## Бесплатный блок

- модель 43;
- опросник архитектуры;
- когнитивная батарея;
- сравнение модели 43 и опросника;
- сохранение сырых когнитивных результатов в объединённый JSON.

Сырые когнитивные показатели не преобразуются в оси 0–100 до появления валидированных внешних норм.
